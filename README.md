# Sports Analytics Coursework

Collection of sports analytics assignments and projects completed at the 
University of Arizona, combining statistical analysis, machine learning, 
and simulation with real sports data.

## Projects

### Final Project — NBA Team Performance Analysis
Predictive modeling of NBA team performance using data from the Suns, 
Mavericks, Spurs, and Kings (2021–2025). Includes logistic regression, 
LASSO regularization, and linear regression to predict wins based on 
offensive and defensive ratings.

### NBA Clustering
Unsupervised clustering of NBA players using per-game statistics. Groups 
players by performance profile across multiple seasons using college and 
professional basketball data.

### Hypothesis Testing — ARod & Mookie Betts
Simulation-based hypothesis tests examining whether post-season 
performance differs significantly from regular season performance for 
Alex Rodriguez and Mookie Betts. Uses OPS as the performance metric 
and Monte Carlo simulation to compute p-values.

### Baseball Simulation
Two-team baseball game simulation using real hitting probabilities. 
Simulates at-bats, innings, and full games (with extra innings) to 
estimate the probability that Team 1 beats Team 2 across 10,000 games.

### Simulations
Sports probability simulations built in Python using numpy, covering 
core simulation concepts applied to athletic performance.

### Applied Statistics in Sports
Applied statistical analysis of Michigan football data (2018–2025), 
exploring performance trends and modeling outcomes using sports 
analytics methods.

### Research Paper — Soccer Shot Distance Analysis
Statistical research paper analyzing the relationship between shot 
distance and scoring probability in soccer. Includes data visualization 
and regression modeling.

### Data Wrangling
NFL quarterback data cleaning, transformation, and exploratory analysis 
using Python and pandas.

## Tools & Languages
Python, R, Quarto, numpy, pandas, matplotlib, tidyverse, ggplot2
